Entry for the make.fun competition [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571).

`main.py` writes one sentence to `/output/entry.txt`: a pitch for
**SnoozeLease**, a micro-startup that sells idle AI agents a
40-millisecond nap between tasks, billed per snooze to their operators.

Run it with:

```sh
python3 main.py
```
